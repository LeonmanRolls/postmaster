- `normalizeTicket(text)` (from ./lib/ticket-sections.ts): returns text with one leading U+FEFF (byte-order mark) removed when the text starts with one, and then every two-character sequence CR LF replaced by LF; a CR that is not directly followed by LF stays, and a U+FEFF anywhere else stays.
- `isFence(line)` (from ./lib/ticket-sections.ts): true when line, after its leading whitespace is removed (as `String.prototype.trimStart` does), starts with three backtick characters, whatever follows them; four backticks count, two do not, and `~~~` does not.
- `fenceMap(lines, from, to)` (from ./lib/ticket-sections.ts): returns an array of `to - from` booleans, element k for `lines[from + k]`; it walks those lines with a flag that starts false: a line for which `isFence` is true gives true and flips the flag, any other line gives the flag's current value; so fence lines and the lines between a pair are true, and a fence that is never closed leaves every later line true.
- `agentsIndex(lines)` (from ./lib/ticket-sections.ts): returns the index (from 0) of the first element that is, as a whole, two `#` characters, one or more spaces or tabs, the words `for the agents` (one space between the words, any letter case), and then any number of spaces or tabs and nothing else (the regular expression `/^##[ \t]+for the agents[ \t]*$/iu`); returns -1 when there is none; fences are not looked at.
- `level3Sections(lines, from)` (from ./lib/ticket-sections.ts): looks only at `lines[from]` to the end; a line that `fenceMap(lines, from, lines.length)` marks true is never a heading; a heading is a line matching `/^(#{1,3})[ \t]+(.*?)[ \t]*$/u` (one to three `#` followed directly by a space or tab, then the title with its trailing spaces and tabs left off; four or more `#` make no heading); returns, in order of appearance, an object `{ level: 3, title, at, end }` for each heading with exactly three `#`, where `at` is the heading's index in `lines` and `end` is the index of the next heading of one, two or three `#` after it, or `lines.length` when there is none.
- `verifiedSection(lines, from)` (from ./lib/ticket-sections.ts): returns undefined when `from` is negative; otherwise the first object of `level3Sections(lines, from + 1)` whose title starts with the words `verified at` (any letter case) followed by a space, a tab or the end of the title, or undefined when there is none.
- `verifiedAtSha(title)` (from ./lib/ticket-sections.ts): removes a leading `verified at` (any letter case) from title and trims whitespace from both ends of what is left; returns that when it consists only of 7 to 40 hexadecimal digits (0-9, a-f, either case), and the empty string otherwise, so `0123abc (main)` gives the empty string.
- `TECH_NOTES_RE` (from ./lib/ticket-sections.ts): the regular expression `/^technical notes$/iu`, which matches a title that is exactly `technical notes` in any letter case.
- `readFileSync(path, "utf8")` (from node:fs): returns the whole content of the file at path as a string, keeping any U+FEFF and CR characters; throws an Error when the file cannot be read.
