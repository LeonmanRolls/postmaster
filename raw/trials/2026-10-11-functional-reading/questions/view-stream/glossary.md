- `scriptsDir(meta)`: given `import.meta`, the absolute directory (symbolic links resolved) that holds the running script file; throws if that file does not exist. The module uses it only to find its own source for `--help`.
- `processIsLive(pid)`: true only if `pid` is a positive integer naming a process that exists and is not a zombie; false for an exited or unknown process, for a zombie, and for 0, negative, fractional or NaN values.
- `digitValue(s)`: turns a non-empty string of Unicode decimal digits (any script, for example `"٣٠"` or `"８０"`) into the same digits as ASCII 0-9, leading zeros kept (`"٠٠٧"` gives `"007"`); throws an Error for an empty string or any other character (sign, space, underscore, letter, superscript digit).
- `PY_S_CLASS`: a string for use inside a regular-expression character class `[...]`; it matches Python's whitespace: U+0009-U+000D, U+001C-U+001F, U+0020, U+0085, U+00A0, U+1680, U+2000-U+200A, U+2028, U+2029, U+202F, U+205F, U+3000 (not U+FEFF, U+200B or U+180E).
- `pyTrim(s)`: like Python's `str.strip()`: removes leading and trailing characters of the `PY_S_CLASS` set and keeps inner whitespace; a string of only whitespace gives `""`.
- `pySplitLines(s)`: like Python's `str.splitlines()`: splits at `\n`, `\r`, `\r\n` (one boundary), U+000B, U+000C, U+001C, U+001D, U+001E, U+0085, U+2028 and U+2029 (not U+001F), drops the boundary characters, gives `[]` for `""`, and adds no empty last item when `s` ends with a boundary (`"a\n"` gives `["a"]`, `"a\n\n"` gives `["a", ""]`, `"a\rb"` gives `["a", "b"]`).
