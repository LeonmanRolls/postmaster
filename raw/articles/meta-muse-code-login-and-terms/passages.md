### MET10 H2 Muse: what "contributor" means
- finding: "Contributor" is a pricing tier name, not a program with other duties: the model id muse-spark-1.3-contributor is the discounted variant for which the user grants Meta permission to train on prompts and completions. The Terms call the same models "Discounted Models" and the Geographic Use Policy lists "Muse Spark 1.2 Contributor" and "Muse Spark 1.3 Contributor" as the Discounted Models.
- quote: "Heavily discounted token pricing in exchange for permission to use your prompts and completions to train future Meta models." (verbatim, pricing page, curl and the fetch tool) ; product-page model table labels: muse-spark-1.3-contributor "Used to improve our products." and muse-spark-1.3 "Not used to improve our products." (verbatim, curl and the fetch tool). What a contributor gives: permission to train on prompts and completions. What it gets: input $0.10 vs $1.25 and output $0.20 vs $4.25 per million tokens (12.5x and 21x lower), cached input $0.002 vs $0.15, but a per-team limit of 100 RPM instead of 3,000 and, under a subscription, no discount at all (Terms 13.4). Muse Code's own default model is the Standard muse-spark-1.2 ("The default model is muse-spark-1.2.", configuration and overview pages, curl and the fetch tool of the overview), so the contributor model has to be chosen with --model or /models.
- source: https://dev.meta.ai/docs/pricing-rate-limits#contributor-tier ; https://dev.meta.ai/legal/geographic-use-policy (Last updated: September 18, 2026) ; https://dev.meta.ai/docs/models#tiers ; read 2026-10-08
