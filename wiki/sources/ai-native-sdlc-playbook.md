# The AI-native SDLC playbook

## What it claims

Anthropic's playbook places design review before code generation and has acceptance of the
plan start implementation [@articles/ai-native-sdlc-playbook].

## What it would mean here

The workhorse spec already records an implementation approach. Reviewing each independent
spec before implementation applies the article's timing to this flow. The postmaster's
one-at-a-time user review and the workhorses' independent specs are this project's design,
not claims made by the article.

The article motivates the change but does not show whether reviewing workhorse specs improves
results here. That remains for runs and issue #9 to measure.
